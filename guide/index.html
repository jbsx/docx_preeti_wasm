What is the Preeti font?

Preeti is a legacy font encoding for Nepali that became the de-facto standard in government offices, newspapers, and publishing houses before Unicode was widely adopted. Like other legacy Nepali fonts (Kantipur, Sagarmatha, Himalaya), Preeti does not store text the way modern systems do: it stores ordinary ASCII bytes that only look like Devanagari when displayed with the Preeti font installed.

That is why Preeti text pasted into a website, email, or phone without the font turns into gibberish Latin characters like g]kfn. The underlying bytes were never Nepali — the font was only pretending.

Why Unicode matters

Unicode (UTF-8) is the international standard for text. Devanagari has a dedicated Unicode block, so Unicode Nepali (नेपाली युनिकोड) works everywhere: search engines can index it, screen readers can read it, and it renders on any modern device with no special fonts installed.

Converting archives of Preeti documents to Unicode (प्रितिदेखि युनिकोड) is usually the first step in digitizing Nepali government records, newspaper archives, and publishing back-catalogs.
